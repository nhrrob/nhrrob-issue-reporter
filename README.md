# NHR Issue Reporter

Client feedback and bug reports for WordPress: a Report button with screenshot markup on every page, an Inbox in the dashboard, and issues sent to GitHub. See `readme.txt` for what it does and how to set it up, `CLAUDE.md` for development commands, and `docs/DECISIONS.md` for why things are built the way they are.

Prepared for WordPress.org on 2026-11-23; installed on nazmulrobin.com/blog.
