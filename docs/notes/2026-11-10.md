# 2026-11-10 and 11: version 0.3.0

## Where things stood

Version 0.2.0 was released on 2026-11-01. Seven issues were open; four of them
(#9, #11, #12, #13) were found that day, by reporting other bugs through the
plugin's abilities on the live blog.

## What was done

All seven, in one pull request as 0.3.0, one commit per issue:

- #11: report and comment text is sent as typed, angle brackets included.
- #9: the similar-issue search uses the title's meaningful words joined with
  OR and ranks by shared words. Checked against GitHub's search first: OR
  keeps the `repo:` and `is:open` qualifiers.
- #6: themes, must-use plugins and other repositories can be reported to; a
  new repository is checked with GitHub when saved.
- #4: the Sent tab filters by repository, with counts; `get-state` takes `repo`.
- #12: comments from the form, the Sent tab and the `comment-on-issue` ability.
- #5: screenshots, uploaded to the media library on send, behind a tick.
- #13: `docs/DECISIONS.md`.

## Left open

- No "Report issue" link on Appearance → Themes: that screen is drawn by
  JavaScript and has no PHP filter for its links. Themes are in the form.
- The blog requires `^0.2`, which does not take 0.3.0. Updating it means
  changing the constraint to `^0.3` in the blog's `composer.json`.
